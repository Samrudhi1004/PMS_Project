# 📌 Product Management System (PMS) with AI Assistant

## 🚀 Overview

The **Product Management System (PMS)** is a web-based application built using Django.
It allows users to efficiently manage product data and includes an integrated **AI Assistant** for intelligent user support.

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, Bootstrap
* **Backend:** Python, Django
* **Database:** SQLite
* **AI Integration:** Python-based AI Assistant
* **Version Control:** Git & GitHub

---

## 🎯 Features

* ➕ Add, Update, Delete Products (CRUD)
* 📋 View Product List
* 🔍 Search & Filter Products
* 📊 Dashboard with Analytics
* 🔐 Authentication (Login/Logout)
* 🤖 AI Assistant for user queries
* 📦 Bulk Product Import using CSV

---

## 🤖 AI Assistant

* Provides guidance to users
* Helps with product-related queries
* Enhances user interaction

---

## 📊 Dataset

* Used a custom **CSV dataset (50+ products)**
* Fields included:

  * Name
  * Description
  * Price
  * Quantity
  * Category
* Implemented bulk upload using Python CSV module

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Samrudhi1004/PMS_Project.git
```

### 2️⃣ Navigate to project

```bash
cd PMS_Project
```

### 3️⃣ Create virtual environment

```bash
python -m venv venv
venv\Scripts\activate
```

### 4️⃣ Install dependencies

```bash
pip install django
```

### 5️⃣ Run server

```bash
python manage.py runserver
```
